# Public assets

Letakkan file statis di sini agar disalin apa adanya oleh Vite.

- `assets/` — gambar & ikon hasil ekspor Figma (`background.png`, `svg/*`).
- `music/` — taruh file backsound di sini, mis. `music/backsound.mp3`,
  lalu sesuaikan `music` di `src/data/wedding.js` (`/music/backsound.mp3`).

Akses dari kode memakai path absolut, mis. `/assets/background.png`.
